1. Login Admin

Akses Awal
  1. Buka halaman Admin Login.
  2. Masukkan username dan password admin.
  3. Setelah berhasil, admin akan masuk ke dashboard sesuai region akunnya.
Data yang terlihat di dashboard mengikuti region admin. Admin Jakarta dan Surabaya tidak saling mengubah data.

2. Mengelola Course & Position

Question Management

Course

Digunakan untuk membuat kategori tes, mengatur position yang boleh mengambil course, dan status publish/draft.

Position

Digunakan untuk membuat pilihan posisi pelamar. Position yang dibuat hanya berlaku untuk region admin tersebut.

Fitur Cara Pakai Catatan
Create Course Klik Create Course, isi nama, deskripsi, pilih position, lalu Publish atau Save as Draft. Course publish dapat dipakai untuk Question Bank.
Edit Course Klik icon edit pada baris course, ubah nama, deskripsi, status, atau position yang terhubung. Gunakan ini untuk menambahkan position baru ke course yang sudah ada.
Toggle Course/Position Gunakan tombol Course atau Position di kanan atas tabel. Tombol ini hanya mengganti tampilan menu.
Add Position Masuk tab Position, klik Add Position, isi nama position, lalu Save. Setelah position dibuat, edit Course yang ingin memakai position tersebut, lalu centang position baru dan simpan.
Filter & Sort Gunakan filter Position/Status dan klik header Name untuk sorting A-Z atau Z-A. Filter aktif setelah tombol Apply ditekan.

3. Mengelola Question Bank

Soal Tes
  1. Klik menu Question Bank.
  2. Klik Create Question Bank.
  3. Pilih course, isi passing score, pilih randomize enable/disable.
  4. Tambahkan soal Multiple Choice atau Essay.
  5. Klik Publish jika sudah siap digunakan.
Fitur Fungsi
Edit Question Bank Mengubah course, passing score, randomize, status publish, serta isi soal yang sudah dibuat.
View Question Bank Melihat detail question bank dan daftar soal tanpa mengubah data.
Question Bank terhubung ke position melalui Course. Jika membuat position baru, tambahkan dulu position tersebut ke Course yang sesuai lewat Edit Course.

4. Melihat Test Results

History
Kolom/Aksi Fungsi
Filter Course/Position Memudahkan admin mencari hasil berdasarkan course atau posisi tertentu.
View Melihat detail jawaban, nilai, course, position, dan status peserta.
Review Essay Melihat jawaban essay peserta dan mengunduh jawaban essay sebagai PDF. Tombol ini nonaktif jika test tidak memiliki essay.
Give Score Menginput nilai essay manual. Jika ingin bobot berbeda, atur bobot Multiple Choice dan Essay. Jika tidak, biarkan 50% dan 50% agar nilai final menjadi rata-rata keduanya.
Jika Question Bank hanya berisi Multiple Choice, nilai langsung final saat peserta submit test.

5. Recapitulation

Rekap Nilai
  1. Buka menu Test Results.
  2. Pilih toggle Recapitulation.
  3. Gunakan filter jika ingin melihat course atau position tertentu.
  4. Klik View untuk melihat semua test milik peserta yang sama.
  5. Klik tombol Email pada baris peserta yang berstatus Passed untuk mengirim email hasil.
Status Arti
Passed Rata-rata nilai final sudah memenuhi passing score.
Not Passed Rata-rata nilai final belum memenuhi passing score.
Waiting for Review Masih ada test essay yang belum disimpan final melalui Give Score.

6. Exam Token

Akses Tes
  1. Buka menu Exam Token.
  2. Klik Generate Token untuk membuat token aktif.
  3. Berikan token tersebut kepada kandidat yang akan mengerjakan tes.
Token bersifat sementara. Jika token kedaluwarsa, admin perlu generate token baru.
